Some of you may wonder why we should care about productivity. While I acknowledge that we shouldn't necessarily care about feeding our corporate masters, I hope most of us can find work we find meaningful.

Productivity as a programmer fundamentally comes down to writing code. There is a fairly low limit to how much code anyone can write in one day. [Various studies][productivity] suggest about 20-30 lines of code on average. So at the core there are two options to increase productivity:

* Get stop doing other stuff so more code can be written. Not a bad idea but there are only 24 hours in a day. You probably can't meaningful increase the number of hours you spend writing code.
* Make each line of code an absolute banger. This is a better approach, as it gives you the possibility for order of magnitude improvements.
